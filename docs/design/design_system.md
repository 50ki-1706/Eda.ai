# Design System

Eda.ai のUIは、**CSS Modules** をスタイリングの主軸とし、**typed-css-modules-mapper** でTypeScriptとの型整合を保つ構成です。
コンポーネントレベルの唯一の依存ライブラリはアイコンの **lucide-react** で、それ以外のUIライブラリ（Material UI、shadcn/ui、Tailwind CSS等）は使用しません。

基本デザイン（レイアウト・余白・角の形状・エレベーション・タイポグラフィの原則）は、**デジタル庁デザインシステムβ版**（https://design.digital.go.jp/dads/）を準拠します。カラーテーマのみ、本プロジェクト独自の `color-palette.md` を使用します。

## 1. ライブラリと基本方針

- **CSS Modules（`*.module.css`）**:
  - スタイリングはすべて CSS Modules で行う。クラス名の衝突をコンパイル時に解決し、コンポーネント単位で `styles.xxx` として参照します。
  - グローバルなリセット・変数は `src/app/globals.css` のみに記述します。
- **typed-css-modules-mapper（TypeScript 7.1 content mapper）**:
  - `tsconfig.json` の `contentMappers` に登録し、`.module.css` のインポートを`.module.css` ファイル自身から直に型付けします（reylo の `.sql` と同じ仕組み）。
  - 生成ファイル（`*.d.ts`）は存在せず、`tsc --runExternalCode` の実行毎にスタイルシートから読み取ります。未定義のクラス参照（`styles.xxx`）は型エラーになります。
  - CSSの構文エラーや `composes` の参照ミスも診断（`css-modules` ソース）として報告されます。
- **lucide-react**:
  - アイコンは lucide-react に統一します（Material Icons、react-icons は使用しない）。
  - アイコンは装飾ではなく意味づけに使い、可能な限りテキストラベル（`aria-label`、可視ラベル）を併記します（デジタル庁デザインシステムのアイコン原則に従う）。

## 2. カラーテーマ

`color-palette.md` を参照（本ドキュメントでは扱わない）。
`globals.css` の CSS 変数（`--color-*`）として定義し、ダークモードは `.dark` クラスで切り替えます。

## 3. レイアウト（グリッド・ブレークポイント）

デジタル庁デザインシステムのレイアウト原則に従います。

- **グリッドシステム**: コンテンツ領域は原則「12カラム+ガター」を基準に考えます。ガターは本文文字サイズの2倍を目安とします。
- **左サイドナビゲーション**: 本アプリは左サイドバー（`Sidebar`）+ メインコンテンツの構成のため、サイドバー右端からマージンを確保します。
- **ブレークポイント**: 1つのみ。**768px未満 = モバイル・タブレット / 768px以上 = デスクトップ**。CSSでは `@media (min-width: 768px)` を使用します。
- **PageContainer (`src/components/common/PageContainer.tsx`)**: 画面全体のルートを包むラッパー。`100vh`・幅100%で、デフォルトで中央配置。レイアウト用のライブラリは使用しません。

## 4. 余白（スペーシング）

デジタル庁デザインシステムの余白のルールに従います。

- **基準単位は 8px**。基準単位の倍率スケールで余白を定義し、本プロジェクトでは次の5段階（`--space-*`）を使用します:

| トークン       | 値    | 主な用途                                   |
| -------------- | ----- | ------------------------------------------ |
| `--space-1` | 8px   | 要素内の小さな余白（アイコンとテキスト等） |
| `--space-2` | 16px  | 関連する要素間の余白                       |
| `--space-3` | 24px  | コンポーネント間の余白                     |
| `--space-4` | 32px  | セクション間の余白                        |
| `--space-5` | 64px  | 重要なセクション・画面レベルの余白         |

- **近接の原則**: 関連する要素には小さな余白、関連の薄い要素には大きな余白を与え、文書構造を視覚的に示します。
- **階層の原則**: 重要度の高い要素にはより大きな余白を与えます。

## 5. 角の形状（ボーダー半径）

デジタル庁デザインシステムにならい、5段階のスタイルを基本の目安とします（`--radius-*`）。

| トークン            | 値     | 主な用途                             |
| ------------------ | ------ | ------------------------------------ |
| `--radius-none` | 0px    | 画像・区切り等、角丸を使わない要素   |
| `--radius-sm`   | 4px    | チップ・小さいUI要素                |
| `--radius-md`   | 8px    | ボタン・アイコンボタン              |
| `--radius-lg`   | 12px   | カード・吹き出し                     |
| `--radius-xl`   | 16px   | モーダル・大きめのカード             |
| `--radius-pill` | 999px  | 特例: メッセージ入力バーなどピル形状 |

- 図形サイズによって同じ角丸値でも視覚的な印象が異なるため、コンポーネントごとに調整して統一感を保ちます。

## 6. エレベーション（シャドウ）

デジタル庁デザインシステムのエレベーション原則に従い、必要 минимумの高低差のみを定義します。

| トークン         | 主な用途                                                     |
| --------------- | ------------------------------------------------------------ |
| `--elevation-1` | ホバーを持つカード、ドロワー・入力欄などの浮き上がり         |
| `--elevation-2` | 固定ヘッダー・バーなど                                       |
| `--elevation-3` | ダイアログ・オーバーレイ表示（原則として表示中のコンポーネントより2段階上） |

- リッチなドロップシャドウは原則使用しません。ドロップシャドウはコントラスト確保の手段ではなく、立体感の表現にのみ使用します。
- オーバーレイの背景は、下層の操作を遮断する演出として `rgba(0,0,0,.4)` 程度のシェードを敷きます。

## 7. タイポグラフィ

- **フォントファミリー**: **Source Code Pro**（Google Fonts、SIL OFL）を全画面で使用します。`next/font/google` で読み込み、CSS変数 `--font-sans` に指定します。コードも本文も同じ等幅フォントで統一し、ターミナル的な世界観を演出します。
- **太さ**: 基本は `400`（N: Normal）と `700`（B: Bold）の2レベル。見出しの強調に `900` を使うことを許容します。
- **大きさ**: デジタル庁デザインシステムの基準に従い、本文・UIは **16px以上** を基準とし、**14px未満は原則使用しません**。補足情報に限り14pxを許容します。

| トークン              | 値     | 用途                       |
| --------------------- | ------ | -------------------------- |
| `--font-size-caption` | 14px   | 補足・キャプション（特例） |
| `--font-size-body`    | 16px   | 本文・UIの基準             |
| `--font-size-md`      | 18px   | 少し大きい本文・小見出し   |
| `--font-size-heading` | 24px   | 見出し                     |
| `--font-size-display` | 32px   | 画面タイトル               |

- **行の高さ**: 本文は最低 `1.5`（本プロジェクトでは `1.7` を標準）。見出しは `1.25` 程度に狭めます。

## 8. アクセシビリティ

- アイコンボタンには必ず `aria-label` を付与します。
- フォーカス表示は `:focus-visible` で全画面共通のアウトラインを表示します。
